# Security

**This release is meant for internal use only.** Run it on a lab machine or
an internal network that you control, operated by people you trust.

Report a vulnerability to support@cheshirelabs.io. Please do not open a public
issue for one.

These drivers move real laboratory instruments. A command reaching a driver can
move an arm or dispense a reagent, so the computer running them, and anything
that can reach it, is the trust boundary.
